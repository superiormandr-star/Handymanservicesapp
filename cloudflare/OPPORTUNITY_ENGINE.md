# Opportunity Engine pilot
This independent ProConnect module manages business prospects, owner-confirmed demo appointments and contracted fees (not received payments). It does not send messages, generate public leads, use an AI model, book customer appointments, or accept payments yet.
Before production: run npm test, apply cloudflare/opportunity-schema.sql to the dedicated ProConnect D1 database via Wrangler, set a new random 32+ character OPPORTUNITY_OWNER_TOKEN Worker secret (never reuse legacy tokens), deploy through the existing Workers Builds branch, and test unauthorized/authorized reads, creation and stage changes in an isolated database. Add the new table to encrypted backup verification before real business records. Do not use consumer PII or enter speculative evidence as fact. No production migration until tests pass.
Next: consent-based client intake, tenant-specific authorization, Calendar availability and confirmed bookings, opt-out controls, separate verified PayPal billing, and AI-assisted scoring with human review. Existing memberships and estimate links remain untouched.
