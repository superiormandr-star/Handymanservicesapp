Alternative OneDrive folder

Microsoft could not access this app's restricted Apps folder. You can connect a dedicated Superior ProConnect Backups folder instead. This requires Microsoft's broader Files.ReadWrite permission, which allows the app to read, modify, and delete files anywhere in your OneDrive. Superior ProConnect's backup code uses only its dedicated folder, and does not delete or move existing files. Only proceed if you approve this wider permission.

Microsoft will ask for your permission again. After it returns here, unlock backups with your owner token to check the connection.

Backups are encrypted before upload to the connected account’s OneDrive application folder. Keep the encryption key securely: it is required for recovery.
